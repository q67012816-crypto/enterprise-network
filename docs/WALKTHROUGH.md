## M3：GraphSAGE 链接预测（`linkpred/src/m3_sage.py`、`linkpred/src/m3_eval.py`）

**它是什么。** GraphSAGE 是一种图神经网络。每家企业先有一个“自身特征”向量，然后每一层把“自己的表示”和“邻居表示的平均值”各乘一个可学习的矩阵再相加，得到新的表示。一层只看直接持股关系的邻居，两层就能间接看到“邻居的邻居”。最后用两家企业的表示算一个分数，分数越高表示模型认为它们在下一年越可能首次出现持股关系。

**输入。**
- 节点特征：与 M1 完全相同的财务特征（对数资产、各比率、经营亏损标记等，按训练年份的 0.5/99.5 分位截断、中位数填补 + 缺失指示）、行业 one-hot（KSIC 前两位，前 20 类 + 其他）、市场（KOSPI/KOSDAQ）。行业与市场是当前值（A3，未验证）。所有标准化统计量只用训练年份（2021、2022）计算。
- 图：年份 t 的持股图 G_t（`data_a2_apionly/graph_t.csv`，A4 方案 a：所有年份只用 API 规则），当作无向图。
- 点对：`pairs.csv` 里已有的正例和每个正例的 100 个负例，与 M0–M2 完全相同。

**邻居信息怎么用。** 对企业 v：`新表示 = W1·自身表示 + W2·(所有邻居表示的平均)`。孤立企业没有邻居，邻居平均为 0，它的表示只来自自身财务、行业、市场特征——所以在“一端孤立”的点对上，GraphSAGE 退化成一个基于特征的模型，而不会像“M1 + 图分数”那样把 CN/AA/Jaccard/PA = 0 这种结构性的低分直接加进去。这正是 Stage 2 要检验的问题之一。

**解码器。** 两种，都属于网格：
- 点积：两家企业表示逐元素相乘再求和；
- MLP：把 `[h_u ⊙ h_v, |h_u − h_v|]` 输入一个两层小网络；这种写法对 u、v 对称。

**训练与选择如何避免泄漏。**
1. 消息传递只用当年的 G_t；要预测的是 t+1 才首次出现的边，这些边本来就不在 G_t 里，也不在历史集合 H_t 里。
2. 训练只用 2021→22、2022→23 的点对；早停看验证集（2023→24）AP，patience 20，最多 200 轮。
3. 网格 32 种配置 × 5 个种子；配置按 5 个种子的平均验证组内 AUC 选（A6，在任何 M3 结果之前提交）。
4. 测试（2024→25）只运行一次：`m3_sage.py test` 加载选定配置的 5 个已训练模型，给测试点对打分并取 5 个种子的平均；若输出文件已存在则拒绝运行。之后没有再调参。
5. 评估（`m3_eval.py`）只读取冻结的分数，组内 AUC / MRR / Hits@10 和混合池 AP 的区间都用按投资方聚类的配对 bootstrap（1000 次，种子 20261103，所有模型共用同一组重抽样）。

**注意。** 2024→25 测试年已被多次查看，M3 的测试数字只能作探索性、相关性解读。
