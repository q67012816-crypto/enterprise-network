# 共同投资图：描述性检查（2026-11-03）

**范围：** 只用训练年和验证年（FY2021→22、2022→23、2023→24），点对来自 `linkpred/data_v3/`，**没有读取测试年 2024→25**。没有调用 API，也没有训练模型。代码：`linkpred/src/coinvest.py`；输出：`linkpred/out_coinvest/`。

## 1. 做法
- **共同投资关系：** 两家合格的上市公司在 FY t 的出资表中，都持有同一家**非上市**主体（非上市公司、基金、投资组合等），就在它们之间记一条共同投资关系。出资行沿用 v3 的规则：api_status 000、期末仍持有、披露日 ≤ C_t。被投资方的名称只做规范化，不做模糊匹配。凡是能解析为上市范围内公司的（现名、股票简称或曾用名），都不算非上市主体，因为它们已经在 G_t 里。
- **hub 处理：** 被超过 20 家上市公司共同持有的主体按基础设施类 hub 剔除，例如各类공제조합、한국예탁결제원。每年约 14–15 个，`top_hubs.csv` 有列表。不设上限的版本也一并报告。
- **增强图：** 增强图 = G_t ∪ 共同投资关系。在增强图上计算共同邻居数和 Adamic–Adar，并与只用 G_t 的结果对比。
- **分组：** 按正例所在的组划分，每个正例保留完整的 101 个候选。

## 2. 覆盖：孤立公司能获得多少邻居（上限 20）
| FY | G_t 中孤立的合格公司 | 其中有共同投资邻居 |
|---|---|---|
| 2021 | 1,429 | 265（19%） |
| 2022 | 1,331 | 297（22%） |

## 3. 信号：正例与负例对比（上限 20；组内 AUC，0.5 = 随机）
| 年份 | 正例组 | n | 增强图中有共同邻居：正例 / 负例 | AA（只用 G_t） | AA（增强图） |
|---|---|---|---|---|---|
| 2021→22 | 全部 | 196 | 25.5% / 6.5% | .539 | **.598** |
| 2022→23 | 全部 | 215 | 24.7% / 8.2% | .533 | **.587** |
| 2023→24 验证 | 全部 | 164 | 27.4% / 8.2% | .556 | **.602** |
| 2021→22 | 两端都有连接 | 118 | 39.0% / 8.2% | .566 | **.659** |
| 2022→23 | 两端都有连接 | 115 | 43.5% / 10.8% | .565 | **.672** |
| 2023→24 验证 | 两端都有连接 | 94 | 46.8% / 10.4% | .600 | **.692** |
| 2021→22 | **一端孤立** | 60 | 5.0% / 4.8% | .497 | .501 |
| 2022→23 | **一端孤立** | 80 | 3.7% / 6.3% | .496 | .488 |
| 2023→24 验证 | **一端孤立** | 58 | 1.7% / 6.1% | .497 | .478 |

**两端孤立：** 只有 12–20 个正例。其中 0%–17% 有直接共同投资，负例约为 0%。正例太少，不作解读。

**一端孤立组为什么没有信号：**
- 孤立的一端多数是被投资方（各年 43/60、60/80、47/58）。
- 22%–34% 的孤立端确实获得了共同投资邻居，但这些邻居和另一端没有交集，所以对“这两家公司会不会建立关系”没有帮助。

## 4. 结论（描述性，单一分数，不是模型）
1. **共同投资信息对“关系发现”有用：** 在全部新边和“两端都有连接”组里，增强图的 AA 比只用 G_t 高 .05–.10 的组内 AUC，三年方向一致。
2. **它解决不了冷启动：** 在“一端孤立”组里，增强图不比随机好，有一年还更差。目前的数据**不支持**把冷启动作为论文的核心贡献。
3. **建议：**
   - 论文主线改为“企业关系发现：公开持股图有观测缺口，用非上市共同投资关系补全”。
   - 冷启动作为如实报告的分组分析和局限，不作为主要卖点。
   - 如果仍想做冷启动，下一个候选是最大股东及特殊关系人数据，需要约 1.5 万次 API 调用。孤立端多数是被投资方，股东一侧的信息更可能对上。这是否有效，**未验证**。

## 5. 限制
- 名称规范化不做模糊匹配，同一非上市主体的不同写法可能被拆开，覆盖率会偏低（未验证）。
- hub 上限 20 是看了持有家数分布后定的，没有看正负例；不设上限的结果方向相同（见 `pos_vs_neg.csv`）。
- 这里只是单一分数的描述，不能代表加入模型后的效果。
